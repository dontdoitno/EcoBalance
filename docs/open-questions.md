# Открытые вопросы и допущения (ASSUMPTION)

## Stage 0

- **ASSUMPTION**: JS package manager — `pnpm` (workspaces через
  `pnpm-workspace.yaml`). Исходное ТЗ называет `uv` для Python, но не
  фиксирует JS-инструмент. Пересмотреть, если появятся явные указания.
- **ASSUMPTION**: стоп-слова для `check-clean` пока не заданы —
  `.stopwords.local` пуст (шаблон из `.stopwords.local.example`).
  Пользователь внесёт список позже; до этого `make check-clean` проходит
  тривиально.
- **ASSUMPTION**: дизайн-скилл `impeccable` недоступен в текущем окружении
  Claude Code на момент Stage 0; пользователь подтвердил, что подключит
  его самостоятельно. До подключения дизайн-этапы (3–5) используют
  `frontend-design` как указано в исходном ТЗ (раздел 4.1).
- **ASSUMPTION**: `docs-src/source/MAIN.md` и `carbon_footprint_dev_spec.md`
  не предоставлены — формулы и поля берутся из раздела 5 исходного ТЗ
  (`PROMPT_CLAUDE_CODE.md`) дословно, как это прямо разрешено автором ТЗ.
- **ASSUMPTION**: `Decimal` vs типизированный `float` для расчётного ядра —
  решение откладывается до начала Этапа 1, когда будет виден объём
  вычислений и тестовых golden-кейсов (см. ADR-0001).

Вопросы без очевидного default-варианта будут добавляться сюда по мере
реализации следующих этапов.
