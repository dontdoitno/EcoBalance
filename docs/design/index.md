# Дизайн

## Бриф

Продукт — B2B SaaS для российских экспортёров химической продукции,
которым европейский импортёр запрашивает данные о встроенных выбросах
для CBAM. Аудитория — технологи, эко-менеджеры, финансовые директора.
Тон — экспертный, спокойный, доказательный: без «эко-клише» (листья,
глобусы, стоковые фото деревьев), числа и методика несут убедительность
сами по себе.

Зелёный цвет из старого прототипа — не догма (как и требовало исходное
ТЗ). Выбрана палитра на основе тёмно-серого/графитового нейтрального
фона с единственным уверенным акцентом (сине-зелёный «индустриальный»
teal, не ярко-зелёный «эко»-зелёный), чтобы не читаться как типовой
экологический стартап-лендинг.

## Токены (`app/globals.css`, `tailwind.config.ts`)

| Токен | Назначение |
|---|---|
| `--color-bg`, `--color-bg-raised`, `--color-bg-sunken` | три уровня фона |
| `--color-text`, `--color-text-secondary`, `--color-text-faint` | иерархия текста |
| `--color-accent`, `--color-accent-strong`, `--color-accent-soft` | единственный акцентный цвет действия |
| `--color-status-{low,significant,critical}-{bg,fg}` | цвета рейтинга hotspots |
| `--radius-{sm,md,lg}`, `--shadow-{sm,md,lg}` | скейл радиусов/теней |
| `--ease-out-exp` | единая кривая анимации |

Светлая и тёмная темы — через `prefers-color-scheme` и явный
`[data-theme]`; статусные цвета (низкий/средний/высокий вклад)
проходят контраст WCAG AA и сопровождаются собственной иконкой
(`components/ui/rating-badge.tsx`), не только цветом.

## Типографика

Inter (Google Fonts, `next/font/google`, подключены `latin` + `cyrillic`
подмножества) — не системный sans по умолчанию, выбран сознательно как
нейтральный, хорошо читаемый для плотного B2B-интерфейса с кириллицей
шрифт.

## Этапы impeccable, выполненные в этом проходе

Дизайн строился с применением карты качества импеккабл
(`craft-floor.md`) по ходу написания каждого экрана: контраст,
состояния (hover/disabled/loading/empty/error), доступность фокуса,
неиспользование запрещённых паттернов (одноразмерные карточки как
структура страницы, kicker-лейблы, gradient-текст и т.п.).

**Не выполнено**: полный интерактивный проход `impeccable audit` и
`impeccable polish` (отдельные команды скилла, запускаемые через живой
dev-сервер с обратной связью от агента) — ограничение объёма этого
прохода, см. `docs/open-questions.md`. Рекомендуемый следующий шаг:
`/impeccable audit` и `/impeccable polish` на лендинге, мастере расчёта
и странице результатов.
