# Руководство пользователя

**Скриншоты не сгенерированы в этой версии** — см.
[ADR-0005](../architecture/adr/0005-deferred-e2e-and-docs-screenshots.md).
Ниже — текстовое описание экранов с точными путями к компонентам, пока
`make docs-screenshots` (Playwright) не подключён.

## 1. Лендинг (`/`)

`apps/web/app/page.tsx`. Hero с ценностным предложением вокруг CBAM,
блок проблемы с интерактивным калькулятором «сколько вы теряете без
первичных данных» (`components/landing/mini-calculator.tsx`), «как это
работает» (4 шага), реальный пример расчёта (числа — фактический вывод
ядра, не иллюстрация), список стандартов, FAQ, CTA.

## 2. Регистрация / Вход

`/register`, `/login`. Email + пароль + название компании. Успешная
регистрация создаёт компанию и ведёт на `/profile`; вход ведёт на
`/dashboard` (или на `next`-параметр, если пользователь был
перенаправлен туда middleware'ом).

## 3. Профиль компании (`/profile`)

Название, ИНН, отрасль, размер, регион энергосистемы (используется как
значение по умолчанию для электроэнергии в новых расчётах — подстановка
из профиля в мастер **не реализована** в этой версии, см.
`docs/open-questions.md`). Список производственных площадок с
возможностью добавить новую.

## 4. Список расчётов (`/dashboard`)

Таблица: название, статус (черновик/финализирован), текущий PCF, дата
создания. Кнопка «Новый расчёт» создаёт черновик и ведёт в мастер.

## 5. Мастер расчёта (`/calculations/[id]`)

Быстрый режим, 4 шага (см. [data-form.md](../methodology/data-form.md)):
продукт → сырьё и энергия → транспорт (опционально) → подтверждение.
Автосохранение на каждом переходе между шагами. Кнопка «Рассчитать»
сохраняет данные и выполняет расчёт, переходя на страницу результатов.

## 6. Результаты (`/calculations/[id]/results`)

Карточки PCF full и CBAM embedded (или причина неприменимости CBAM),
горизонтальная диаграмма разбивки по категориям (цвет = рейтинг
hotspot), таблица hotspots с рейтингом (значок + подпись, не только
цвет). Баннер демо-коэффициентов, если применимо. Кнопки «Построить
сценарий» и «Скачать отчёт».

## 7. Сценарии (`/calculations/[id]/scenarios`)

Список применимых мер (чекбоксы), после выбора и клика «Пересчитать
сценарий» — столбчатая диаграмма «до/после», дельта по PCF и, если
применимо, по CBAM embedded. Ссылка на отчёт по этому сценарию.

## 8. Отчёты (`/calculations/[id]/reports`)

Три карточки (PCF, CBAM, Сценарий — последняя видна только если пришли
со страницы сценария с `scenario_id`), каждая с кнопками PDF/XLSX/JSON.
Скачивание — реальный файл с сервера (не клиентский рендеринг).
