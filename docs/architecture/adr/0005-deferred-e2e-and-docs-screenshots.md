# ADR-0005: Playwright e2e и скриншоты документации отложены

- Статус: принято (сознательная граница объёма этого прохода)
- Дата: 2026-10-29

## Контекст

Исходное ТЗ требует e2e-тест Playwright полного пути («регистрация →
быстрый расчёт → hotspots → сценарий → отчёт CBAM») в составе Этапа 4,
и скриншоты для `docs/user-guide/` через Playwright-скрипт
(`make docs-screenshots`) в составе Этапа 6.

## Решение

Не реализовано в этом проходе. Вместо e2e-теста весь путь был
многократно проверен вручную через `curl` против живого
FastAPI+Postgres и против живого Next.js dev-сервера (ответы,
middleware-редиректы, SSR-вывод) — см. транскрипт сессии. Реальный
браузерный рендеринг (визуальная проверка, клики, скриншоты) не
выполнялся — используемое окружение не имело подключённого браузерного
расширения в момент сборки.

## Почему отложено, а не сделано частично

Playwright e2e и скрипт скриншотов — это отдельная инфраструктура
(установка браузеров, фикстуры, CI job), которая добавляет заметный
объём работы поверх уже реализованных Stage 1–6. Притворяться, что
они «частично готовы» написанием теста, который никогда не запускался
в реальном браузере, было бы хуже, чем прямо зафиксировать отсутствие.

## Последствия

- `docs/user-guide/index.md` не содержит скриншотов — описывает экраны
  текстом с точными путями к файлам компонентов.
- CI (`.github/workflows/ci.yml`) не содержит e2e job — только
  lint/types/unit+integration tests/docs build/check-clean.
- Рекомендованный следующий шаг: установить Playwright
  (`pnpm add -D @playwright/test && pnpm exec playwright install`),
  написать сценарий по пути из `docs/product/demo-script.md`, добавить
  `make docs-screenshots` и e2e job в CI.
