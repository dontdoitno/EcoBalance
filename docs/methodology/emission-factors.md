# База коэффициентов выбросов

**Все коэффициенты в этой версии — демонстрационные (`is_demo=True`),
не верифицированы ни по одной реальной базе данных (Ecoinvent, Carbon
Minds, GaBi, Росстат и т.п.).** Каждый коэффициент несёт `source="demo"`,
`year`, `is_demo=True` на уровне кода (`ecobalance_core/reference.py`) и
на уровне БД (`EmissionFactor`, заполняется `scripts/seed.py`). UI и
отчёты показывают это явным предупреждением (`demo_factors`
data-quality flag, баннер на страницах результатов/сценариев и в самих
отчётах).

## Справочники (демо-версия)

| Категория | Количество записей | Примеры |
|---|---|---|
| Топливо (`FUELS`) | 8 | природный газ, нафта, уголь, мазут, дизель, пропан, водород, биомасса |
| Сырьё (`RAW_MATERIALS`) | 12 | природный газ-сырьё, нафта-сырьё, этилен, пропилен, хлор, серная кислота, аммиак, CO₂, бензол, изопропанол |
| Регионы энергосистемы (`REGIONS`) | 8 | ОЭС Центра/Северо-Запада/Юга/Средней Волги/Урала/Сибири/Востока, изолированные |
| Транспорт (`TRANSPORT_MODES`) | 6 | автомобильный, железнодорожный, морской, речной, воздушный, трубопроводный |
| Обращение с отходами (`WASTE_TREATMENTS`) | 5 | захоронение, сжигание, переработка, компостирование, сброс в воду |
| Продукты (`PRODUCTS`) | 7 | аммиак, мочевина, сульфат аммония (CBAM-применимы), этанол, полиэтилен, ПВХ, ацетон |

Расширение относительно исходного прототипа (3 вида транспорта, 5
регионов, 4 вида сырья) — выполнено, как требовало исходное ТЗ.

## Версионирование и воспроизводимость

Каждый `Calculation` хранит `factor_version` (сейчас фиксированная
строка `"demo-2024"`); при появлении второй версии справочника это
поле позволит воспроизвести расчёт на той версии коэффициентов, с
которой он был сделан изначально (`PROMPT_CLAUDE_CODE.md` §6: «снимок
входных данных и версии справочника коэффициентов для
воспроизводимости»). Полноценный механизм версионирования нескольких
одновременно живущих версий справочника — не реализован (одна «живая»
версия на данный момент).

## Замена на верифицированные данные (следующий шаг)

Замена демо-коэффициентов на реальные — отдельная задача, не
выполненная в этой версии: нужен реальный источник (поставщик базы
данных ещё не определён в проекте), процесс обновления `EmissionFactor`
без потери воспроизводимости старых расчётов, и снятие флага
`demo_factors` только для записей, которые были фактически заменены.
