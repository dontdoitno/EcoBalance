# Методология: обзор

EcoBalance реализует расчёт углеродного следа химической продукции по
жизненному циклу (LCA), совместимый с ISO 14067:2018 (в РФ — ГОСТ Р
ИСО 14067-2021), GHG Protocol и ISO 14064-1, с учётом отраслевого
руководства TfS PCF Guideline и требований CBAM.

## Этапы LCA, которые отражает ядро

1. **Цель и границы** — `CalculationInput.boundary`
   (`cradle_to_gate`/`cradle_to_border`/`cradle_to_grave`),
   `functional_unit`, `gwp_set`.
2. **Инвентаризация (LCI)** — ввод по топливу, сырью, энергии,
   транспорту, отходам, технологическим/факельным/фугитивным выбросам.
3. **Оценка воздействия (LCIA)** — `engine.calculate` переводит
   инвентарные данные в кг CO₂-экв. по Scope 1/2/3 (CH₄/N₂O через GWP).
4. **Интерпретация** — hotspots (Парето-ранжирование), флаги качества
   данных, сценарии оптимизации.

## Что исправлено по сравнению с прототипом

Полный список — в `architecture/adr/0001-stack.md` и `open-questions.md`,
но ключевые методологические исправления:

- Сырьё — Scope 3 (upstream), не Scope 1.
- Нет «базового следа продукта по умолчанию», подставляемого при нулевых
  данных — отсутствие данных явно отражается как 0 или ошибка валидации,
  не маскируется.
- Эффект мер оптимизации — пересчёт модели, не процент с «магическими»
  числами.
- Единицы измерения конвертируются только явно, с проверкой наличия
  НТС/EF, а не через фиксированные множители внутри формулы.
