# Обзор методологии

Статус: план — наполняется в Этапе 1 (расчётное ядро).

Методика основана на LCA (ISO 14040/14044), ISO 14067:2018 (в РФ — ГОСТ Р ИСО
14067-2021), GHG Protocol, ISO 14064-1, отраслевом TfS PCF Guideline и
требованиях CBAM. Этапы LCA: цель и границы → инвентаризация (LCI) → оценка
воздействия (LCIA) → интерпретация.
