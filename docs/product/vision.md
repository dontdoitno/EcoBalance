# Видение продукта

Статус: план, наполняется по этапам.

EcoBalance — сервис для российских экспортёров химической продукции
(удобрения, полимеры, нефтехимия), которым европейский импортёр запрашивает
данные о встроенных выбросах для CBAM. Без верифицированных первичных данных
применяются завышенные default-значения, повышающие стоимость
CBAM-сертификатов.

Целевая аудитория, сценарии использования и границы MVP будут подробно
описаны при реализации Этапа 4 (ЛК) и Этапа 5 (лендинг).
