# Видение продукта

EcoBalance — сервис для российских экспортёров химической продукции
(удобрения, полимеры, нефтехимия), которым европейский импортёр
запрашивает данные о встроенных выбросах для CBAM. Без верифицированных
первичных данных применяются завышенные default-значения, повышающие
стоимость CBAM-сертификатов — ключевая боль, вокруг которой строится
продукт.

## Целевая аудитория

- Технологи и эко-менеджеры производственных площадок — вводят данные о
  процессе, читают карту «слабых мест».
- Финансовые директора — читают оценку стоимости CBAM (факт vs
  default), принимают решение об инвестициях в меры снижения.

## Границы MVP (этот прототип)

Реализовано: лендинг, аутентификация, профиль компании и площадок,
мастер расчёта в быстром режиме, расчёт по методике LCA/ISO 14067 с
корректным разведением Scope 1–3 и CBAM embedded emissions, карта
hotspots с флагами качества данных, сценарии оптимизации через
пересчёт модели, отчёты PCF/CBAM/сценарий в PDF/XLSX/JSON.

Не реализовано (явно, не скрыто — см. `docs/open-questions.md` и
`docs/architecture/adr/`): полный режим мастера (разделы 0–8),
верифицированные коэффициенты выбросов (сейчас все демонстрационные),
e2e-тесты и скриншоты руководства пользователя, полноценный
интерактивный проход `impeccable audit`/`polish`, ротация
refresh-токенов, журнал аудита (`AuditLog` создан в схеме, не
подключён к эндпоинтам).

## Сценарии использования

1. Технолог регистрируется, заполняет профиль компании, создаёт расчёт
   в быстром режиме для одного продукта, получает PCF и hotspots.
2. На основе hotspots выбирает меры оптимизации (например, переход на
   электроэнергию с низким EF), видит пересчитанный след и дельту.
3. Финансовый директор смотрит мини-калькулятор на лендинге или блок
   «оценка стоимости» в отчёте CBAM, чтобы аргументировать инвестицию
   в первичные данные перед руководством.
4. Для CBAM-неприменимого продукта система прямо говорит об этом и
   предлагает альтернативный PCF-отчёт — не подставляет чужую форму
   отчёта молча.
