# EcoBalance

Платформа расчёта и снижения углеродного следа химической продукции с
формированием отчёта для CBAM (ISO 14067 / GHG Protocol / LCA).

Рабочий прототип для акселератора. Экспортёры химической продукции
(удобрения, полимеры, нефтехимия) рассчитывают Scope 1–3 по методике
LCA, получают карту «слабых мест», моделируют меры снижения выбросов
пересчётом модели и формируют отчёт PCF (ISO 14067) или CBAM.

Полная документация: [`docs/`](docs/index.md) (методология, архитектура,
API, фронтенд, дизайн, эксплуатация, тестирование, руководство
пользователя) — см. `make docs-serve`.

## Монорепозиторий

```
apps/
  web/        Next.js 15, React 19, TypeScript — лендинг, ЛК
  api/
    ecobalance_core/   расчётное ядро (LCA/CBAM, без зависимостей от FastAPI/БД)
    app/               FastAPI: auth, CRUD, отчёты
packages/
  contracts/  OpenAPI → TypeScript клиент
docs/         mkdocs-документация
```

## Запуск

```bash
cp .env.example .env
docker compose up --build   # или: make up
make migrate                # миграции Alembic
make demo                   # migrate + демо-данные (демо-пользователь + 3 компании)
```

- Web: http://localhost:3000
- API: http://localhost:8000/health
- Docs: http://localhost:8001

Демо-логин: `demo@ecobalance-demo.ru` / `demo12345` — сценарий
демонстрации: [`docs/product/demo-script.md`](docs/product/demo-script.md).

## Подробная инструкция: запуск на Windows (для тех, кто делает это впервые)

Этот раздел — пошаговая инструкция для человека, у которого на компьютере
ещё ничего не установлено. Весь процесс займёт 20–40 минут (в основном —
время на скачивание программ). Ничего не нужно знать про программирование.

### Шаг 1. Установить Docker Desktop

Docker — это программа, которая запускает весь проект (сайт, сервер,
базу данных) одной командой, без ручной установки Node.js, Python,
PostgreSQL и т.д.

1. Откройте в браузере: https://www.docker.com/products/docker-desktop/
2. Нажмите **Download for Windows**.
3. Запустите скачанный файл `Docker Desktop Installer.exe` двойным
   кликом.
4. В установщике оставьте галочку **Use WSL 2 instead of Hyper-V**
   включённой (это стандартная и рекомендуемая настройка) и нажмите
   **Ok** / **Install**.
5. После установки Windows попросит **перезагрузить компьютер** —
   согласитесь.
6. Если при первом запуске Docker Desktop появится сообщение про
   **WSL 2 update** со ссылкой — перейдите по ней, скачайте и установите
   **WSL2 Linux kernel update package**, затем снова откройте Docker
   Desktop.
7. Запустите **Docker Desktop** из меню «Пуск». Дождитесь, пока в левом
   нижнем углу окна иконка кита станет **зелёной** и появится надпись
   «Engine running» — это значит, что Docker готов к работе. Оставьте
   Docker Desktop открытым (можно свернуть) на всё время работы с
   проектом — без него ничего не запустится.

### Шаг 2. Установить Git

Git нужен, чтобы скачать код проекта с GitHub.

1. Откройте https://git-scm.com/download/win — скачивание начнётся
   автоматически.
2. Запустите установщик. Во всех окнах мастера установки можно нажимать
   **Next**, ничего не меняя (настройки по умолчанию подходят).
3. На последнем шаге нажмите **Install**, затем **Finish**.

### Шаг 3. Скачать код проекта

1. Нажмите на кнопку **Пуск**, введите `Git Bash` и откройте программу
   **Git Bash** (это появилось после установки Git — чёрное окно с
   командной строкой).
2. Решите, в какую папку скачать проект, например на рабочий стол.
   В Git Bash введите (замените `ВАШЕ_ИМЯ` на имя пользователя Windows,
   которое видно в начале строки приглашения, или просто используйте
   `cd ~/Desktop` для рабочего стола):
   ```bash
   cd ~/Desktop
   ```
3. Скачайте проект (вставьте в Git Bash свою ссылку на репозиторий,
   если она отличается):
   ```bash
   git clone https://github.com/ohhhhnooo/EcoBalance.git
   ```
4. Перейдите внутрь скачанной папки:
   ```bash
   cd EcoBalance
   ```

### Шаг 4. Создать файл с настройками окружения

Проекту нужен файл `.env` с настройками (пароли для локальной базы
данных и т.п.). Он не хранится в репозитории по соображениям
безопасности, но есть готовый шаблон.

В том же окне Git Bash (вы уже должны быть в папке `EcoBalance`):
```bash
cp .env.example .env
```
Эта команда скопирует шаблон `.env.example` в рабочий файл `.env`.
Для локального запуска ничего в нём менять не нужно — значения по
умолчанию уже подходят для первого запуска на своём компьютере.

### Шаг 5. Запустить проект

Всё ещё в Git Bash, в папке `EcoBalance`, выполните:
```bash
docker compose up --build
```

Что произойдёт:
- Docker скачает и соберёт всё необходимое (базу данных, сервер,
  сайт). **В первый раз это может занять 5–15 минут** — в окне будет
  бежать много технического текста, это нормально.
- Когда сборка закончится, в окне появятся логи работающих сервисов
  (`web`, `api`, `db`, `docs`) — они продолжат печататься построчно.
  Это означает, что всё запущено и работает. **Не закрывайте это окно**,
  пока пользуетесь сайтом — если его закрыть, сайт остановится.

### Шаг 6. Подготовить базу данных (один раз)

Пока окно из Шага 5 продолжает работать, откройте **новое** окно Git
Bash (Пуск → Git Bash), перейдите в ту же папку и выполните две
команды:
```bash
cd ~/Desktop/EcoBalance
make migrate
make demo
```
- `make migrate` — создаёт таблицы в базе данных.
- `make demo` — заполняет базу демонстрационными данными: тестовым
  пользователем и тремя примерами компаний с расчётами.

Если команда `make` не находится (ошибка вида `make: command not
found`), значит у вас не установлен `make` — это нормально для чистой
Windows. Вместо `make migrate` и `make demo` выполните:
```bash
docker compose exec api uv run alembic upgrade head
docker compose exec api uv run python scripts/seed.py
```

### Шаг 7. Открыть сайт в браузере

Откройте любой браузер (Chrome, Edge, Firefox) и перейдите по ссылке:

- **Сайт:** http://localhost:3000
- Проверить, что сервер работает: http://localhost:8000/health
  (должна появиться строка вида `{"status":"ok"}`)
- Документация проекта: http://localhost:8001

Для входа используйте демо-аккаунт:
- **Email:** `demo@ecobalance-demo.ru`
- **Пароль:** `demo12345`

Сценарий демонстрации возможностей — в
[`docs/product/demo-script.md`](docs/product/demo-script.md).

### Как остановить проект

Вернитесь в окно Git Bash, где запускали `docker compose up --build`
(Шаг 5), и нажмите **Ctrl + C**. Это остановит все сервисы.

### Как запустить проект повторно (в другой день)

Всё, что уже скачано и собрано, повторно скачивать не нужно:
1. Запустите **Docker Desktop** из меню «Пуск» и дождитесь зелёного
   индикатора «Engine running».
2. Откройте Git Bash, перейдите в папку проекта (`cd ~/Desktop/EcoBalance`).
3. Выполните:
   ```bash
   docker compose up
   ```
   (без `--build` — пересобирать заново не требуется, если вы не меняли
   код).
4. Откройте http://localhost:3000.

### Частые проблемы

- **«Docker Desktop requires a newer WSL kernel version» или окно с
  просьбой обновить WSL** — перейдите по ссылке из сообщения, скачайте
  и установите обновление, перезапустите Docker Desktop.
- **Иконка кита Docker Desktop серая / «Engine starting»** долго —
  подождите 1–2 минуты после запуска Windows, Docker стартует не
  мгновенно. Если не помогает — перезагрузите компьютер.
- **`port is already allocated`** (порт 3000/8000/5432/8001 занят) —
  на компьютере уже что-то использует этот порт (например, другой
  локальный сервер). Закройте конфликтующую программу или остановите
  предыдущий запуск проекта (`docker compose down` в папке проекта).
- **Сайт на http://localhost:3000 не открывается, хотя в консоли всё
  «зелёное»** — подождите ещё 10–20 секунд после появления логов: веб-
  приложению и API иногда нужно чуть больше времени на старт после
  сборки, затем обновите страницу браузера.
- **`git: command not found` в Git Bash** — значит Git Bash не
  переустановился после установки Git; закройте окно и откройте новое
  через меню «Пуск» → «Git Bash».
- Если ничего не помогает — полностью остановите и пересоберите:
  ```bash
  docker compose down
  docker compose up --build
  ```

## Разработка без Docker

```bash
# API
cd apps/api
uv sync --all-groups
DATABASE_URL=postgresql+asyncpg://ecobalance:<пароль>@localhost:5432/ecobalance \
  uv run uvicorn app.main:app --reload

# Web
cd apps/web
pnpm install
pnpm dev
```
